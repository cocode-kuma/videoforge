# cocode 酷码工作室 · Cocode Studio VideoForge

分类：bug-fix

## Problem

用户反馈 HTTP 500、装饰性省略号误似可点击菜单、部分控件无反馈以及原生下拉菜单风格不一致。

## Decision

AppError 使用 Symbol.for 标记跨独立插件产物识别，保留具体 HTTP 状态及友好信息。新增返回 null 的匿名会话查询用于正常首屏，受保护接口继续要求认证。新增独立构建产物的集成测试，覆盖服务之间实际传递的错误，避免仅测试 TypeScript 共享模块时漏检。

| Before | After | Why |
| --- | --- | --- |
| 静态三个点 | 删除 | 避免没有用途的菜单暗示 |
| 原生 select | 自定义深色 listbox 弹层、选中状态、选项解释 | 与工作室一致，支持点击、方向键、Enter、Escape、外部关闭 |
| 空白输入时按钮无响应 | 点击显示输入要求并聚焦输入框 | 明确告知下一步 |
| 未生成视频显示播放形按钮 | 分镜图标及明确等待说明 | 区分占位展示与实际播放 |
| 弹窗错误在遮罩背后 | 弹窗内显示错误 | 让操作失败可见 |
| 全屏 Promise 未处理 | 捕获失败并提示使用播放器控制 | 避免静默无响应 |

## Alternatives considered

未为省略号发明无需求功能。没有通过统一返回 200 隐藏业务错误；正常匿名首屏使用专门查询，其余接口保留正确状态。未改变页面总体布局和视觉风格。

## Consequences

固定模型、数据隔离和三个插件结构保持。独立产物回归纳入 npm run check。原生下拉替换后，浏览器测试覆盖自定义控件的鼠标与键盘路径。

## 环境事实

esbuild 为三个插件分别打包 shared/contracts.ts，产生不同 AppError 构造函数。仅用 instanceof 默认比较会把数据服务的 401 当成 UI 插件中的未知异常，最终返回 500。生产日志中的“请先登录”及打包产物测试复现了该问题；Symbol.for 共享标记解决构造函数身份差异。
