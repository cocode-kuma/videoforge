# cocode 酷码工作室 · Cocode Studio VideoForge

分类：feature

## Problem

用户希望在左侧每个项目旁的三点菜单中重命名或删除，顶部按钮距离项目太远。

## Decision

项目行拆成选中项目按钮和相邻的独立菜单按钮，避免嵌套 button。操作菜单通过 portal 显示以免被可滚动列表裁切，支持鼠标、方向键、Escape 和点击外部关闭。删除进行中项目时显示不可用原因。顶部的重命名和删除入口移除。

弹窗独立保存目标项目，不把当前打开项目当作操作目标。操作其他项目不会切换工作区，删除非当前项目也不会关闭当前作品；删除弹窗注明项目名称。

## Alternatives considered

未把菜单点击绑定到选中项目动作，也未保留重复顶部入口。

## Consequences

API 和多租户隔离保持原样。浏览器回归覆盖操作非当前项目、保持当前工作区、键盘关闭和删除后列表更新。
