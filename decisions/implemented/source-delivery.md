# cocode 酷码工作室 · Cocode Studio VideoForge：源码交付

用户要求部署文档与包含 DSH 的完整源码压缩包。

交付保留三个插件及应用源码、测试、锁定依赖、启动脚本与部署示例。DSH 使用官方 0.1.0-rc.6 发布提交的原始仓库归档，以及独立校验官方 SHA-512 的 npm CLI 原包；不改动 DSH 核心。npm 元数据未声明 gitHead，来源文件明确区分发布源码提交与 npm 构建产物，不宣称可重现构建认证。

源码包通过显式目录与根文件清单生成，不包含运行数据、密钥、依赖安装目录、日志或开发机生成状态。打包脚本检查 DSH 来源校验、上游版本及 TypeScript 源文件存在，再检查 ZIP CRC 和每个交付文件的 SHA-256。部署依赖通过 npm ci 联网安装，不承诺离线环境。

部署手册提供 Windows 本地、Linux systemd、Docker + 宿主 Nginx、单实例要求、备份恢复和排错步骤。systemd 和 Docker 配置未在开发机实际部署，文档明确验证边界。交付前检查曾出现一次队列测试失败；加入失败日志断言信息后，独立队列测试和完整源码测试重跑通过，未复现原始失败，未据此修改业务逻辑。
