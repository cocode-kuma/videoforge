# 酷码工作室官网接入清单

当前项目已经完成官网会员接入边界、积分目录、扣费预估、Token 使用量记录和远程额度预占/提交/释放适配器。以下事项需要官网开发者权限或官方接口信息后才能完成。

## 账号 SSO

- OIDC/OAuth 发行方地址（issuer）
- 授权地址、Token 地址、用户信息地址
- Client ID、Client Secret
- 测试环境和正式环境
- 回调地址白名单
- 用户唯一标识字段（建议使用不可变 subject）
- 需要的 scopes
- 退出登录和 Token 刷新规则

## 会员与积分

- 查询会员信息和套餐信息的接口
- 查询积分余额的接口
- 积分预占接口
- 成功扣除接口
- 失败释放接口
- 取消、超时、退款和补偿规则
- 幂等键字段和有效期
- 接口鉴权方式、签名方式和错误码
- 是否允许课件、视频、Agent 共用同一个积分账户

## Token 口径

- 输入、输出、reasoning、缓存 tokens 是否全部计费
- 模型调用失败是否扣费
- 重试是否重新计费
- 最低 50 积分按单次模型调用还是按任务计算
- 小数积分的舍入方式
- ChatGPT、Claude 等国外模型的具体换算方式

## 当前代码中的临时行为

- 未配置官网接口时，使用本地开发账号和本地积分钱包。
- 视频任务的实际预占仍是开发阶段的 1/2/4 credits。
- Token 使用量会记录到任务结果，并生成计费预估，但在官网扣费合同确认前不会自动替换现有扣费。
- DeepSeek V4.1 Flash 使用 `deepseek-flash` 模型 ID，服务端仍通过 `DEEPSEEK_BASE_URL` 与 `DEEPSEEK_API_KEY` 调用。
